# atlas-dev-hub

A community space for developers building with the [ATLAS platform](https://atlas.motionapplied.com) — the telemetry and data platform behind motorsport, aerospace, and engineering at Motion Applied.

This is where you share what you've built, contribute examples, ask questions, and connect with other engineers using ATLAS.

## Related orgs

- **[Software Products](https://github.com/Software-Products)** — Apache-licensed source code: Stream API, Protocol, Common, KeyGenerator, Router
- **[ATLAS Documentation and Examples](https://github.com/mat-docs)** — Official documentation, API references, and curated examples


## Getting started

New here? Start with the [ATLAS documentation](https://atlas.motionapplied.com/getting-started/quick-start/) then come back to explore what the community has built.

Want to contribute? Read the [contribution guide](../CONTRIBUTING.md) — it covers everything from submitting an example to raising a bug.

Have a question? Open a [discussion](https://github.com/orgs/atlas-dev-hub/discussions) — Q&A, ideas, and show-and-tell are all welcome.
